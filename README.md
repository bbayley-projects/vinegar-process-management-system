# Vinegar Process Management System (VPMS)

**Author:** Brenon Bayley  
**Portfolio:** Process Improvement | Data Analytics | Power BI | Information Technology

## Project Overview

The Vinegar Process Management System (VPMS) is a process-management and decision-support framework developed to improve production visibility, reporting consistency, process monitoring and access to operational information within a manufacturing environment.

The original project combined standardized process documentation, KPI monitoring, issue tracking, production reporting and Power BI dashboards into a structured management framework.

This repository presents a **sanitized portfolio reconstruction** of the project using fictional or non-sensitive demonstration data.

> **Confidentiality Notice:** This repository does not contain proprietary company data, internal records, supplier information, production specifications or confidential operational documentation.

## Business Problem

Operational information can become fragmented across production records, spreadsheets, emails and individual reports. This makes it more difficult to:

- Monitor production performance
- Identify recurring operational issues
- Track key performance indicators
- Retrieve historical information
- Maintain standardized process documentation
- Present management information consistently

VPMS was designed to provide a more structured information and reporting framework around these activities.

## Solution

The framework brings together several components:

- Standardized process documentation
- Structured production records
- KPI monitoring
- Issue tracking and follow-up
- Weekly performance reporting
- Production scheduling and calendar views
- Distribution monitoring
- Power BI dashboards
- Trend and performance analysis

## Dashboard Framework

The project was structured around several management views:

| Dashboard | Purpose |
| --- | --- |
| Calendar | Production activity and scheduling visibility |
| Distribution | Monitoring distribution-related activity |
| Mash Weekly | Weekly monitoring of mash-related activity |
| Weekly Performance | KPI and operational performance monitoring |
| Issues | Tracking operational issues and follow-up |
